# Simon

Consegna 1 (intermedia) del progetto di **ESP**. Consiste in un primo prototipo verso l'implementazione del gioco
[Simon](https://en.wikipedia.org/wiki/Simon_(game)).

### Dispositivi
- Pixel 9 (fisico)
    - Android 16
- Pixel 5 (emulatore)
    - Android 17

### Ambiente di sviluppo
- Android Studio Panda 1 (version: 21.0.9)
- neovim (version: 0.11.1)
